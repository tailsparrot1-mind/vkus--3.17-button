# Vkus 3.26 — референс нижней карточки и общий поиск ЦА

## Что изменено

1. Правый нижний блок приведён к визуальному референсу `vkus/assets/birzha_reference.png`: карточка «Опции анализа» с пунктами:
   - Определение намерения
   - Подбор ниши
   - Оценка спроса
   - Уведомления о новых заявках
   - кнопка «Настроить»
2. Линейный график, не соответствовавший референсу, из правого нижнего блока удалён.
3. В строке поиска добавлены две отдельные команды:
   - «Найти ЦА» — поиск по выбранным основным источникам;
   - «Все источники» — общий охват шести основных источников одновременно: VK, Telegram, Avito, YouDo, Профи.ру, Форумы.
4. Подсказка в поле поиска приведена к нишам бизнеса: цветочный магазин, доставка еды, салон красоты.
5. Для будущих коннекторов формируется `exchange_search_request` с полями: `query`, `scope`, `sources`, `city`, `radius`, `period`, `category`, `audience_signals`.
6. Версия в нижней строке интерфейса обновлена на 3.26.

- Поисковые коннекторы не подключены. Нажатия формируют и показывают структуру запроса, но не собирают реальные публикации/объявления.
