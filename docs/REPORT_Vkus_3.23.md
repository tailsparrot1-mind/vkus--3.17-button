# Vkus 3.23 — корректировка иконок и дополнительных источников

## Что изменено

1. **Avito:** увеличен и визуально центрирован знак в KPI-карточке; исходный PNG нормализован в прозрачный квадрат, чтобы убрать оптическое смещение.
2. **Форумы:** заменена малоконтрастная практически невидимая пиктограмма на яркий знак двух диалоговых облаков. Иконка отображается в плитке «Форумы».
3. **«Ещё 5»:** вместо заглушки открывается отдельное окно-каталог с пятью плитками:
   - Яндекс — «Скоро»;
   - Google — «Скоро»;
   - Одноклассники — «Скоро»;
   - Юла — «Скоро»;
   - Ещё одна площадка — «В разработке».
4. Для дополнительных площадок подготовлены локальные PNG-иконки. Внешние ресурсы при запуске не загружаются.
5. Номер сборки в интерфейсе обновлён до 3.23.

## Проверки

- `python -m compileall -q vkus tools` — PASS.
- Запуск реального окна `VkusApp` и проверка переключателей источников, категорий, города, периода графика и навигации — PASS.
- Проверка каталога дополнительных источников: найдено ровно пять плиток, присутствуют все пять названий и статус «В разработке» — PASS.
- Скриншоты реального окна получены в разрешениях 1672×941 и 1366×768.
- Скриншот каталога дополнительных источников получен отдельно.
- ZIP проверен через `ZipFile.testzip()`.

## Ограничения

Плитки дополнительных площадок являются элементами каталога/визуального интерфейса. Интеграции Яндекса, Google, Одноклассников и Юлы ещё не подключены; статусы «Скоро» и «В разработке» это явно показывают. Наличие иконок не означает, что поиск по этим площадкам уже работает.
