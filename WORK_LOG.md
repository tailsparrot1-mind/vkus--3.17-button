## История работ

### 2026-11-15 — Защищённое сохранение облачной сессии и обработка временных ошибок

**Статус:** изменения внесены в рабочую ветку; итоговая проверка последнего CI требует подтверждения.

**Что реализовано:**
- Добавлено сохранение данных облачной сессии через системное хранилище учётных данных (keyring): Windows Credential Manager / Linux Secret Service при доступности.
- Сохранённая запись включает access token, refresh token, пользователя и срок действия.
- Открытый текстовый файл или небезопасный резервный способ хранения токенов не используется.
- Если системное хранилище недоступно, сессия остаётся только в памяти до закрытия приложения.
- При запуске приложения выполняется попытка восстановить сессию и обновить токен.
- При выходе из аккаунта сохранённые данные сессии удаляются.
- Добавлена зависимость `keyring>=25.2`.
- Ошибки HTTP теперь сохраняют код ответа в `CloudMarketplaceError`.
- Временные сетевые ошибки и серверные ошибки не должны удалять сохранённые учётные данные; удаление выполняется при ответах, указывающих на недействительную/отозванную сессию (400/401/403).
